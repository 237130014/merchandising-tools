# 吉客云货品档案字段抽查

对吉客云「货品档案导出」表做**字段级信息抽查**，按 8 条业务规则筛出**疑点清单交人工复核**（基调：只筛疑点、不自动判错），并在原表尾部写入「核查结果 / 问题摘要」两列供逐行核对。

## 何时使用

- 用户给出一份吉客云货品导出/档案表（通常命名为 `*货品导出*.xlsx`），要求「抽查 / 核对 / 查疑点 / 筛问题」
- 用户要求把核查结论写回原表，或用「通过 / 未通过 / 免检」标记每行
- 用户提到渠道/品牌口径：中央、唯一、老凤祥、中国珠宝、珍尚银、IU、TY、萃华、周大金

## 工作流

1. **确认输入表**：读取表头，确认含 条码 / 规格 / 货品编号 / 货品名称 / 成分 / 银重(规) / 工费价格(规) / 字印要求(规) / 分类 / 抽检比例(规)。脚本按表头名自动定位列，缺失时回退到默认列序。
2. **跑抽查引擎**：`python scripts/audit.py --src "<被核查表.xlsx>"`，输出疑点清单（6 个 sheet）。
3. **写回原表**：`python scripts/write_back.py --src "<被核查表.xlsx>" --issues "<疑点清单.xlsx>"`。
4. **交付**：用 present_files 呈现核查版原表与疑点清单，并口头汇报命中分布与需要人工确认的边界项。

## 脚本

```bash
PY="C:/Users/23713/.workbuddy/binaries/python/envs/default/Scripts/python.exe"   # 已装 openpyxl

# 1) 抽查（默认输出到被核查表同目录，文件名自动加日期后缀）
$PY <skill>/scripts/audit.py --src "E:/.../10-15-2货品导出.xlsx"

# 2) 写回核查列（自动识别并复用已有的「核查结果 / 问题摘要」列）
$PY <skill>/scripts/write_back.py --src "E:/.../10-15-2货品导出.xlsx" \
                                  --issues "E:/.../10-15-2_抽查疑点清单_20261016.xlsx"
```

- `audit.py` 参数：`--src`（必填）、`--out`（可选，输出路径）、`--sheet`（可选，工作表名）
- `write_back.py` 参数：`--src`、`--issues`（必填）、`--sheet`、`--no-backup`
- 两个脚本都不改原始数据列，只在表尾追加/更新两列

## 8 条规则速览

| # | 规则 | 一句话口径 |
|---|---|---|
| 1 | 属性/品牌四列一致 | 条码属性 = 编号前2位 = 分类；条码品牌标记 ↔ 编号末位 ↔ 规格【品牌】。**数字段一律不校**；★唯一 ≡ TY（末位 A/T 互通） |
| 2 | 成分 ↔ 银重/工费 | 计价 → 银重、工费必须纯数字；一口价 → 豁免 |
| 3 | 货品名称证书措辞 | 品牌组（中央/老凤祥/珍尚银/中国珠宝/萃华）须含「配国检证书」；非品牌组（唯一/IU/TY/周大金）按材质判「配证书」 |
| 4 | 银含量三列统一 | 规格 / 货品名称 / 字印要求 等级一致；三列均未写 = 不含银 → 免检 |
| 5 | 产品名一致 | 规格【品牌】后首个括号前的产品名须出现在货品名称中 |
| 6 | 字印要求前缀 | 老凤祥→老鳳祥｜中国珠宝→中珠｜珍尚银→中国黄金｜周大金→周大金｜唯一/IU/TY→FY/MY/ZZ/足银｜萃华→CH｜中央→只有银含量 |
| 7 | 抽检比例非空 | `抽检比例(规)` 为空即疑点 |
| 8 | 手镯银重取中间值 | 手镯规格 `11-13g` → 银重写 `12`；规格 `12g` → 写 `12` |

**完整口径、品牌/属性对照表、12 条人工豁免口径 → 读 `references/rules.md`**（规则改动或用户补充口径时，也更新该文件）

## 硬性约定

- 结论基调是**筛疑点**，不要自行判「错」。措辞用「疑点 / 待人工确认」。
- 包材产品（编号属性码 `BC` 或 分类=包材）**整行免检**，核查结果写「免检」。
- 条码带 `WC`（外采）/ `CK`（工厂测款）→ **不查字印要求**。
- 品牌一致性**一律比代号，不比品牌名文字**（表里「老鳳祥」是繁体，按名字比会误报）。
- 以下 3 项**不纳入自动核查**（需看图识别），要到人工清单里逐条标注为「需看图识别」：
  规格材质完整性、规格工艺完整性、禁用商贸俗称材质名（如「火山岩」）。

## 已知坑

- **被核查表若正在 Excel 中打开**，`write_back.py` 会报 `PermissionError` → 提示用户先关闭 Excel；不要用 COM 强行保存（用户可能有未保存改动），可先输出「核查版」副本。
- **O 盘 / P 盘（`\\winy\公司文件`、`\\Winy1\商品图片`）文件内容读不到**（`PermissionError`，但能列目录）→ 用 Excel COM 只读打开后导出。
- 向工作区根目录写文件偶尔被安全策略拦截，可先写 `.workbuddy/tmp/` 再复制。
- 条码存在多套形态（IU 品牌自成一套 `I`+字母+数字、`bc###` 后缀、`SH` 后缀等），解析不了的会单列进「条码形态待识别」sheet，**不要猜**。
