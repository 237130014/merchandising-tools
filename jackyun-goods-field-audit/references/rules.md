# 吉客云货品档案抽查 · 完整规则口径（v1.0 / 2026-10-16 封版）

## 一、被核查表结构

吉客云「货品档案导出」单 sheet 表，第 1 行表头，其余行为**规格记录**（一个货品编号可挂多条规格）。共 16 列：

| 列 | 字段 | 说明 |
|---|---|---|
| A | 条码 | SKU 条码 |
| B | 规格 | 规格全称，含品牌标签【…】 |
| C | 货品编号 | 12 位档案编号 |
| D | 货品名称 | 简短名称（= 产品名 + 银含量 + 证书后缀） |
| E | 成分 | 计价 / 一口价 |
| F | 银重(规) | 银重或整重 |
| G | 工费价格(规) | 工费 |
| H | 配件要求(规) | 配件描述 |
| I | 字印要求(规) | 字印内容 |
| J | 电镀要求(规) | 电镀工艺 |
| K | 镶嵌材质(规) | 镶嵌材质 |
| L | 规格默认供应商 | 供应商代码 |
| M | 供应商货号(规) | 供应商侧货号 |
| N | 分类 | 项链/手链/戒指/耳饰/手镯/吊坠/包材/金礼… |
| O | 清仓备注(规) | 新品/滞销款/平销款 |
| P | 抽检比例(规) | 抽查策略 |

## 二、编码规则

### 货品编号（12 位）= 2 + 5 + 4 + 1
- **前 2 位**：产品属性拼音首字母 —— 项链 `XL`、手链 `SL`、耳饰 `ES`、戒指 `JZ`、手镯 `SZ`、吊坠 `DZ`、包材 `BC`、银礼 `YL`、金礼 `GG`
- **中 5 位**：产品字符代码，取「新品条码表」第 1 列顺延的 5 位编号
- **再 4 位**：出条码年月（如 2026.9.10 → `2609`）
- **末 1 位**：品牌代号字母

### 货品条码 = 5 位产品代码 + 属性 + `4`，按品牌换拼装位置

| 品牌 | 条码形态 |
|---|---|
| 中央 | `ZY` + 代码 + 属性 + `4` |
| 唯一 | 代码 + 属性 + `4`（无标记） |
| 老凤祥 | `FX` + 代码 + 属性 + `4` |
| 中国珠宝 | 代码 + 属性 + `4` + `ZZ` |
| 珍尚银 | `SY` + 代码 + 属性 + `4` |
| IU | `IU` + 代码 + 属性 + `4` |
| TY | 代码 + 属性 + `4` + `TY` |
| 萃华 | `CH` + 代码 + 属性 + `4` |
| 周大金 | `DJ` + 代码 + 属性 + `4` |

- 条码尾部的 `WC` / `CK` 是**商品性质标记**：`WC` = 外采商品，`CK` = 工厂提供测款商品。
- **条码的数字段与货品编号的数字段允许不一致**（双轨），抽查时**只校产品属性与品牌，数字段一律不管**。
- 已知例外形态：条码中带 `bc###`（如 `1414XL4TYbc160`）、以 `SH` 结尾、末位数字为 `5`（如 `1359SL5WC`）—— 解析脚本容忍这些形态，不报错。

## 三、8 条抽查规则

> 基调：**只筛疑点、不自动判错**，全部交人工复核。

### 规则1 · 属性 / 品牌 四列一致
- 条码属性 = 货品编号前 2 位 = 分类对应属性
- 条码品牌标记 ↔ 编号末位代号 ↔ 规格【品牌】
- **★ 唯一 与 TY 为相等信息**：编号末位代号 `A` / `T` 互通，条码标记亦互通。

### 规则2 · 成分 ↔ 银重 / 工费
- 成分只能是「计价」或「一口价」
- **计价**：银重(规)、工费价格(规) 必须是**纯数字**（空 / 文字备注 / 区间 `18-20` / `-` 均为疑点）
- **一口价：豁免**（允许为空）

### 规则3 · 货品名称证书措辞
| 品牌组 | 要求 |
|---|---|
| 中央 / 老凤祥 / 珍尚银 / 中国珠宝 / 萃华 | 货品名称必须含「**配国检证书**」 |
| 唯一 / IU / TY / **周大金** | **不得出现**「配国检证书」；规格已写「配证书」→ 货品名称须体现「配证书」；否则 足银999系 或 含天然石 → 须含「配证书」；925 且无天然石 → 不得写「配证书」 |

- 「配国检证书」与「配证书」**不是同一个意思**：只有品牌组写国检证书。
- **合成立方氧化锆不算天然石**（因此 `s925 + 合成立方氧化锆` 不应写配证书）。
- **周大金不需要配国检证书**（2026-10-16 补）。

### 规则4 · 银含量三列统一
规格 / 货品名称 / 字印要求 三列的银含量**等级**须一致（写法可不同）：
- `s925` ≡ `S925` ≡ `银925` ≡ `925银`
- `足银9999` ≡ `足银999.9`（99.99%）
- 三列**均未写**银含量 = 本就不含银（玉石、包材类）→ 免检
- 规格里只写「银色」（颜色）不算含量

### 规则5 · 产品名一致
`货品名称 = 规格产品名 + 银含量 + 证书后缀`
规格产品名 = 规格【品牌】之后、第一个括号前的那段文字，必须出现在货品名称中。

### 规则6 · 字印要求前缀
| 品牌 | 应以…开头 |
|---|---|
| 老凤祥 | `老鳳祥` |
| 中国珠宝 | `中珠` |
| 珍尚银 | `中国黄金` |
| 周大金 | `周大金` |
| 唯一 / IU / TY | 工厂代号：`FY` / `MY` / `ZZ` / `zz` / `ZG` / `YG` / `足银` |
| 萃华 | `CH` |
| 中央 | **只有银含量描述**（如 `足银999`、`S925`），不得夹带其他内容 |

豁免：条码带 `WC` / `CK`（外采、工厂测款）**整项免检**；无银含量（非金属材质）字印可为空。

### 规则7 · 抽检比例非空
`抽检比例(规)` 为空即疑点。

### 规则8 · 手镯银重取中间值
手镯（货品编号属性码 `SZ` 或 分类 = 手镯）：
- 规格写**重量区间**（如 `11-13g`）→ 银重(规) 必须填**中间值**（`12`）
- 规格写**唯一值**（如 `12g`）→ 银重必须填该值
- 规格**无重量信息**（玉髓等非金属款）→ 跳过，单列「手镯无重量信息」sheet

## 四、对照表

- **品牌**：中央 `K`/前缀 `ZY`｜唯一 `A`/无标记｜老凤祥 `F`/前缀 `FX`｜中国珠宝 `R`/后缀 `ZZ`｜珍尚银 `Y`/前缀 `SY`｜IU `B`/前缀 `IU`｜TY `T`/后缀 `TY`｜萃华 `H`/前缀 `CH`｜周大金 `Z`/前缀 `DJ`
- **属性码**：`XL` 项链｜`SL` 手链｜`ES` 耳饰｜`JZ` 戒指｜`SZ` 手镯｜`DZ` 吊坠｜`BC` 包材｜`YL` 银礼｜金礼 = 条码 `GC` / 编号 `GG`
- **性质后缀**：`WC` 外采商品｜`CK` 工厂测款
- **天然石**（需配证书）：和田玉、玛瑙、玉髓、青金石、芙蓉石、蜜蜡、木变石、翡翠、水晶、发晶、欧泊、海蓝宝、石榴石、长石、葡萄石、尖晶石、碧玺、孔雀石

## 五、人工复核口径（已知业务豁免）

1. 规格里已写「配证书」→ 货品名称体现「配证书」即通过（不按材质反推）
2. 三列均未写银含量 = 本就不含银 → 规则4 免检
3. 非金属材质（无银含量）无法打字印 → 字印为空不算问题
4. 条码带 `WC` / `CK`（外采、工厂测款）→ 不检查字印要求
5. 包材产品（属性码 `BC`）→ **整行跳过核对**（核查结果记「免检」）
6. 萃华 → 归入品牌组，须含「配国检证书」
7. 周大金 → 字印以「周大金」开头为正确；**不需要配国检证书**
8. `TY` 与 `唯一` 为相等信息（末位代号 `T`/`A` 互通）
9. **不纳入自动核查**（需看图识别）：规格**材质完整性**、规格**工艺完整性**、**禁用商贸俗称材质名**（如「火山岩」）

## 六、输出物

1. **疑点清单 xlsx**（`<被核查表名>_抽查疑点清单_<YYYYMMDD>.xlsx`），6 个 sheet：
   - 疑点清单：`行号 | 条码 | 货品编号 | 规格品牌 | 命中规则 | 规则名称 | 问题字段 | 实际值 | 期望/说明 | 人工结论`
   - 汇总统计 / 条码形态待识别 / 天然石词表边界 / 手镯无重量信息 / 规则说明
   - 同一行命中多条规则 → 出多行，方便人工逐条过
2. **写回被核查表**：「核查结果」（未通过／通过／免检）+「问题摘要」（该行多条问题合并一格）两列，一个商品只看一行。
